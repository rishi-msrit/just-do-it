# Just Do It! A Clarity Toolkit

I built this because I kept getting stuck.

Not stuck on hard problems, stuck on basic ones. Should I take this internship? Which project do I work on first? Is this decision even worth stressing over? I'd spend hours going in circles and end up doing nothing.

I have ADHD, which makes decision fatigue hit differently. Most productivity tools either overwhelm you with features or oversimplify things to the point of being useless. I wanted something in between — tools that actually teach you *how* to think, not just tell you what to do.
So I built this.

### Live Link: https://just-do-itt.vercel.app/index.html
---

## What it is

A collection of 18 decision-making and self-reflection frameworks things like SWOT Analysis, Ikigai, the Eisenhower Matrix, First Principles thinking presented in a clean, calm interface where you can actually *use* them, not just read about them.

Every tool has:
- A simple explanation of what it is and when to use it
- An interactive input section where you fill in your own situation
- A visual result that makes the framework actually mean something
- A PDF export so you can keep what you made

No accounts. No data saved anywhere. No AI doing the thinking for you. Just you and the framework.

---

## Who it's for

Anyone who feels like they have too many options and not enough clarity. Students, early-career people, people changing direction, people who just need to think something through without opening a 40-tab research spiral.

If you already know which framework you need, go straight to it. If you don't, the homepage asks you what you're struggling with and suggests where to start.

**Problem Solving**
- 5 Whys
- First Principles Thinking
- Fishbone Diagram

**Goals**
- SMART Goals
- WOOP Goal Setter

## Tech

Pure HTML, CSS, and JavaScript. No frameworks, no npm, no build tools. The entire project is under 300KB. Opens in any browser, works offline once loaded.

## Run it locally

```bash
git clone https://github.com/rishi-msrit/clarity-toolkit.git
cd clarity-toolkit
# Open index.html in your browser. That's it.
```

No installs. No setup. Just open the file.
